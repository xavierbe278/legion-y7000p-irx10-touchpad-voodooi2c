# 触控板排错清单

按顺序检查，前一步不通过就不用往下走。

## 1. 驱动有没有加载

```sh
kextstat | grep -i voodoo
```

- 没有 `VoodooI2C` → 检查 `OSBundleLibraries` 里的 `VoodooI2CServices` 依赖是否已删除
- 有 `VoodooI2C` 但没有 `VoodooI2CHID` → 检查 HID 依赖是否被 Block

## 2. 控制器有没有绑定

```sh
ioreg -rc VoodooI2CControllerDriver | grep -c class
```

- `0` → PCI 匹配没命中。检查 `VoodooI2CPCILakeController` 的 `IOPCIMatch` 是否含 `0x7a7c8086&0xFFFCFFFF`
- `2` 以上 → 正常（本机有额外一个空控制器也会被绑）

## 3. 中断模式

```sh
ioreg -l -w0 -rc VoodooI2CDeviceNub | grep -E 'Interrupt Mode|gpioIRQ'
```

| 输出 | 含义 |
|---|---|
| `GPIO` + `gpioIRQ = 8` | ✅ 正常 |
| `APIC` | GPIO 驱动不认本机 GPIO 控制器（`INTC1085`），换 GPI0 1.1.5 |
| 空 | `_CRS` 没提供中断资源，检查 `SSDT-GPI0` 与 `GPI0 _STA → XSTA` |

## 4. 指针抖动

- 检查 PS/2 触控板 / 鼠标是否关闭（`VoodooPS2Trackpad` / `VoodooPS2Mouse`）
- 确认 boot-args **没有** `-vi2c-force-polling`

## 5. 手势缺失

- `VoodooInput.kext` 必须启用（`VoodooI2C.kext/Contents/PlugIns/VoodooInput.kext`）
- 注意：`VoodooPS2Controller.kext/Contents/PlugIns/VoodooInput.kext` 要**关闭**，否则两个 VoodooInput 冲突
